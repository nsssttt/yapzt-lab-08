# Lab 08 - Test Design

The CSV files contain synthetic examples for boundary value analysis, decision tables, equivalence partitioning, pairwise testing, and state transition testing. They use only generic roles and values. No real user data is included.

Open the CSV files in a spreadsheet application to review or edit the cases. The PlantUML sources describe the booking state machine and task board state transitions.

## Render the diagrams

With PlantUML installed, render the source files as SVG:

```sh
plantuml -tsvg *.puml
```
